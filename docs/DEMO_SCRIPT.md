# Phase 1 environment walkthrough

1. Launch the Windows executable and enter campus.
2. Orbit/pan/zoom to establish scale and inspect the representative academic block.
3. Select a facility, show its stable ID and explicitly illustrative resource profile.
4. Focus, return to overview, and move across the different campus districts.
5. Observe environmental life and the infrastructure indicators.
6. Pause/resume the clock and restart the session.

This demonstrates the environment foundation, not the later resource-management campaign. Do not describe initial metrics as working interventions or claim phone functionality in this phase.
